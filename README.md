## 🏫 Overview

**MIPS Academic ERP Suite** adalah portofolio sistem informasi terpadu yang menggabungkan 3 modul utama dalam siklus operasional sekolah & pondok pesantren:

1. **[SIM Tendik & Guru (app-dataguru)](https://github.com/PrestianHanif/app-dataguru)**: Manajemen direktori pendidik, pegawai *onsite/stay*, struktur organisasi hierarkis, dan arsip alumni guru.
2. **[SIM Santri & Buku Induk Digital (app-datasantri)](https://github.com/PrestianHanif/app-datasantri)**: Digitalisasi lembar buku induk resmi, penomoran NIS otomatis, pelacakan riwayat mutasi santri pindahan, dan rekapitulasi rombel.
3. **[Portal PMB Terpadu (app-pmb)](https://github.com/PrestianHanif/app-pmb)**: Sistem pendaftaran murid baru online dengan *smart conditional branching logic* (Santri Baru vs Santri Pindahan) dan portal pengumuman kelulusan.

## 💻 Tech Stack & Architecture

* **Backend:** PHP 7.4 / 8.2 (CodeIgniter 3 MVC Architecture)
* **Database:** MySQL (Relational Schema, Foreign Keys, Normalized Tables)
* **Frontend:** Bootstrap 5, AdminLTE, jQuery, DataTables, FontAwesome, Chart.js
* **Reporting:** FPDF / PHPSpreadsheet (Excel & PDF Export)
* **Workflow:** Git, GitHub Desktop, AI-Augmented Engineering (Google Antigravity)
